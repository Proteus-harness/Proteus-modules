## Границы

ContextBuilderModuleHost не предоставляет callback cancellation: здесь введён
локальный deadline, а новый wire callback не добавлен. Ptyxis по-прежнему
сохраняет полный вывод во временные capture-файлы; disk quota этим исправлением
не обещается. Для ограниченного сохранения нужен обычный source_capture.

Отдельных claims об ускорении, RSS/CPU, live provider interoperability и
нативном UI нет. Исследовательские DCP/tool-output-artifacts исключены из
shipping scope. Документированные ограниченные shell semantics OpenCode и
pinned patch semantics не переписывались как якобы новые дефекты.
